# @purple-brock/burrow-native

Purple Brock Burrow for React Native / Expo — `<Chamber>` (box) and `<Tunnel>` (text) styled from tokens, plus `useBurrow()`. No ThemeProvider: switch theme with `BadgerBase.setMode`.

**Needs:** React ≥ 18, React Native ≥ 0.73 (Hermes-safe). ESM only.

Part of **Purple Brock Burrow** by The Purple Brock.

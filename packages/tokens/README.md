Design tokens for Purple Brock Burrow — the primitive + semantic token schema, default theme (AA-checked in light and dark), and colour tools (`generateScale`, `generateHarmonics`, `generateTheme`).

**Needs:** Any JS/TS project (no React needed). ESM only.
